## Overview

**HZ Catering** is a conversion-focused marketing site for a catering business — a single, smooth-scrolling page on a rich `#0F0F0F` dark palette, designed to showcase the food, build trust, and funnel visitors straight into an enquiry. Package selection flows directly into the contact form, and a floating WhatsApp button makes reaching out one tap away.

## ✨ Highlights

- 🖼️ **Cinematic hero** with clear calls-to-action (*Book Now* / *View Menu*) and smooth in-page scrolling
- 🥂 **Services & Menu** sections presenting offerings with appetite appeal
- 💰 **Pricing plans** that pre-fill the contact form when a plan is chosen
- 📸 **Gallery, testimonials & About** to build credibility
- 📱 **Floating WhatsApp button** for instant enquiries
- 📐 **Fully responsive** — tuned for mobile-first viewing

## 🧱 Tech Stack

- **React 18 + TypeScript**, bundled with **Vite**
- **Tailwind-style utility CSS** with MUI + Radix UI primitives
- Component-driven layout with smooth scroll + section anchors

## 🚀 Getting Started

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm run build   # production build
```

## 🗂️ Structure

```
src/app/
├── components/   # Navigation, Hero, Services, Menu, Gallery, Pricing,
│                 # WhyChooseUs, Testimonials, About, Contact, Footer, WhatsAppButton
└── App.tsx       # composes the landing page + plan→contact flow
```
